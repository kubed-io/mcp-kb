# The saga (frozen)

The design record from before mcp-kb used superpowers. It's kept for history: code comments
still cite its decisions as `§C1.n`, which are sections of
[Chapter 1](Chapter_1_The_Card_Catalogue.md).

Nothing is added here. What the server does is [the spec](../superpowers/specs/); how later
changes were designed and built is [the history](../superpowers/plans/). Where the saga and the
spec disagree, the spec is right.
